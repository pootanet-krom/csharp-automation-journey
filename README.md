# C# Automation Journey 

Learning C# for industrial automation — from console basics to PLC communication and real-time web dashboards.

##  Goal
Build practical tools that connect shop-floor equipment (Siemens S7 PLC, Factory I/O) to databases and web dashboards.

##  Roadmap
- [x] Week 1 – C# fundamentals (variables, input, calculations)
- [ ] Week 2–3 – Collections, file I/O, LINQ
- [ ] Week 4–5 – OOP & event-driven design (machine state machine)
- [ ] Week 6–8 – PLC communication (Sharp7, Modbus TCP, Factory I/O SDK) + HMI
- [ ] Week 9–11 – SQL, ASP.NET Core Web API, Blazor dashboard
- [ ] Week 12 – Unit tests & documentation
